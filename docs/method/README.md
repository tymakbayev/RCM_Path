# Метод

[`LLM_engineering_research_T.A.Astana2026.pdf`](LLM_engineering_research_T.A.Astana2026.pdf) — эссе автора о том, как
велось это исследование: «От "так никто не делает" к исполняемой гипотезе: как использовать несколько LLM для
инженерных исследований». Публикуется без изменений, в редакции от 2026-10-03.
sha256 `2639e1524e75e06637198d80815e60658cc269e4b655a1292740d8ed2b8e2f01`.

Принципы, которые в нём описаны:

- **Assume → Build → Break**: допустить, что нужные свойства достижимы, построить добросовестный прототип и попытаться
  его опровергнуть;
- **модели предлагают, человек направляет, эксперимент решает** — несколько моделей (GPT, Claude, Gemini, Qwen,
  DeepSeek) с ручной оркестрацией;
- **отрицательные результаты — часть знания**.

Там же разобрано, где метод опасен: предвзятый отбор человеком, ложный консенсус моделей, неподходящие сравнения,
общая ошибка кода и теста.

Сквозной пример эссе — более ранний этап того же проекта: сжатие содержимого, эксперименты JARVIS-LM E20–E23. Их
числа взяты из результатов того времени, которых в этом репозитории нет. Адресный движок (A2–A8) сделан позже по той
же практике: протоколы фиксируются до прогонов, вторая модель выступает рецензентом, неудачи записываются как неудачи.
