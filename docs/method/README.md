# Методика

[`LLM_engineering_research_T.A.Astana2026.pdf`](LLM_engineering_research_T.A.Astana2026.pdf): «От "так никто не
делает" к исполняемой гипотезе: как использовать несколько LLM для инженерных исследований». Редакция от 2026-10-03,
опубликована без изменений. sha256 `2639e1524e75e06637198d80815e60658cc269e4b655a1292740d8ed2b8e2f01`.

Основные положения:

- Assume → Build → Break: допустить достижимость требуемых свойств, построить добросовестный прототип и попытаться его
  опровергнуть;
- модели предлагают варианты, исследователь направляет работу, спорные утверждения решаются экспериментом;
- отрицательные результаты сохраняются вместе с условиями, при которых вывод следует пересмотреть.

Отдельно разобраны риски метода: предвзятый отбор, ложный консенсус моделей, неподходящие сравнения, общая ошибка кода
и теста.

Сквозной пример в тексте относится к более раннему этапу того же проекта (сжатие содержимого, эксперименты JARVIS-LM
E20-E23); их данные в этот репозиторий не входят. Эксперименты A2-A8 выполнены по той же методике: протоколы
фиксируются до прогонов, каждый этап проходит независимое ревью, неудачи фиксируются наравне с успехами.
